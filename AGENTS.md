# Agent Instructions

This repo is a mixed-purpose toolbox of scripts organized by tool/domain directory.

For Bash script conventions, see `skills/create-bash-script/SKILL.md`.

## Keep the README in sync

When adding a new top-level script/tool directory:
1. update the "Tools" section in `README.md` so the project tree includes the new directory.
2. add each new script under that tree using a compact single-line entry: script path, short description, and requirements.
3. do this as part of the same change; do not leave it for later, because missing entries make tools harder to discover.
